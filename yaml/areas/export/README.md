# yaml/areas/export/

DB → YAML snapshots. Each area is a subdirectory named after its keyword,
containing one file per section:

```
midgaard/
  area.yaml      # area header fields
  rooms.yaml     # all rooms with exits and extra descriptions
  mobs.yaml      # all mobiles with loot, specials, and scripts
  objects.yaml   # all objects with affects and extra descriptions
  resets.yaml    # all resets (mob/object/equip/give/put/door/randomize)
  shops.yaml     # all shops keyed by keeper_vnum
```

Generated by:
    python3 tools/yaml_export.py --area <keyword>
    python3 tools/yaml_export.py --all-areas

Do not edit these files directly — they are overwritten on each export.
